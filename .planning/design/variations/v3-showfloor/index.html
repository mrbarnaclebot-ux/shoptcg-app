Why it reads as made by a person

  1. Photographs, not gradients. Every mood in this direction comes from a lamp in a real-feeling hall. The UI stays flat and crisp on top.
  2. Two materials. Galaxy black is the hall. Warm paper is what you hold: tickets, receipts, the sign. Nothing is glass.
  3. Orange is lamplight. It marks where to look: the table number, the hold timer, the one button. It is never a background wash.
  4. Type like event signage. A condensed poster face, set big enough to crop. Body copy in a plain newsprint grotesk, sentence case, no tracked caps.

Reading the table

  1. Table B14 in orange, top right. Same number as the cardboard on the case, so a buyer wandering off can find their way back.
  2. "Under market" is a rubber stamp, outlined and two degrees off true, like a sticker a vendor slapped on. It never fills with colour.
  3. Prices are set in the poster face. Big, condensed, tabular. The second currency whispers underneath.
  4. The list bar is a ticket stub. Paper, perforated, torn off the hall. It is the one light object on the page, so it reads as "yours".
  5. On hold gets a hatch, like tape across a case, plus plain words about when it comes back.
